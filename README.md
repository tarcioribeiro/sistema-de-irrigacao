#Sistema de Irrigação Inteligente

Projeto de extensão desenvolvido por discentes da Estácio Campus Belém na disciplina Aplicação de Cloud, IoT e Indústria 4.0 em Python .
O objetivo foi criar um protótipo funcional de segurança inteligente, acessível e sustentável para ambientes domésticos e hortas urbanas.

##Objetivos

Automatizar a transparência com base em dados de umidade do solo;
Reduzir o consumo de água em pelo menos 30%;
Promover práticas sustentáveis ​​e acessíveis;
Integrar IoT, sistemas embarcados e computação em nuvem.
##Tecnologias Utilizadas

ESP32 (microcontrolador com Wi-Fi integrado);
Sensor FC-28 (umidade do solo);
Módulo Relé + Bomba d'água;
Blynk Cloud (monitoramento e controle móvel);
Painel Web (HTML, CSS, JavaScript, hospedado no GitHub).
##Estrutura do Projeto

Montagem do circuito físico (sensor, relé, bomba e ESP32);
Programação do ESP32 para coleta de dados e acionamento automático;
Integração com Blynk Cloud para controle via aplicativo mobile;
Dashboard Web para visualização em tempo real e histórico de precisão.
##Resultados

Protótipo funcional validado em ambiente doméstico;
Eficiência hídrica comprovada, acionando segurança apenas quando necessário;
Aplicabilidade prática para pequenos cultivadores urbanos.
